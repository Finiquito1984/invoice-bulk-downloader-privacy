# Privacy policy — Invoice Bulk Downloader for Amazon

Public privacy policy for the Chrome/Edge extension **Invoice Bulk Downloader for Amazon**, in English and Portuguese.

This repository is served with GitHub Pages (main branch, site root):

- English: https://finiquito1984.github.io/invoice-bulk-downloader-privacy/
- Portuguese: https://finiquito1984.github.io/invoice-bulk-downloader-privacy/pt/

The contact form uses a free [Web3Forms](https://web3forms.com) access key in `site-config.js`. The destination inbox is set only in the Web3Forms dashboard; do not put an email address in these files.
